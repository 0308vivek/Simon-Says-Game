# Simon Says Game

This project is a simple implementation of the classic Simon Says memory game, developed using pure HTML, CSS, and JavaScript. It is created for learning and practicing fundamental JavaScript concepts.

## Features
- Interactive color-based memory game
- Increasing difficulty with each level
- Keyboard-controlled game start
- Visual feedback for user interaction

## Technologies Used
- HTML
- CSS
- JavaScript (Vanilla)

## Learning Objectives
- DOM manipulation
- Event handling
- JavaScript arrays and logic building
- Timers and asynchronous behavior

## How to Run
1. Clone the repository
2. Open `index.html` in a web browser
3. Press any key to start the game
